# Contributing

Thank you for looking at swift-app-sessions.

This public repository is a published copy. Development happens in a private monorepo, and each release is copied here with its tag, so changes made directly in this repository are overwritten by the next release.

## Issues

Open issues here. Include the smallest example that reproduces the problem, the package version, and the platform and tool versions you use.

## Pull requests

Pull requests here are read, but they are not merged here. A change we take is re-applied upstream and arrives in this repository with the next release.
